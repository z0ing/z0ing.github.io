### 1. 概念定位（它在地图上的位置）
这是整个多线程大厦的**地基**。如果你不理解“进程”和“线程”的区别，不知道线程是怎么被创建和跑起来的，后面学锁、学线程池就会像空中楼阁，完全无法理解底层在干嘛。

### 2. 基础知识回顾（温故知新）
因为这是我们的第一个概念，不需要回顾前置的Java多线程知识。但你必须知道一个常识：**Java程序是从 `main()` 方法开始执行的，这个 `main()` 方法本身就运行在一个线程里，我们称之为“主线程”。**

### 3. 基础常态用法速授（事实性知识直给环节）
> 💡 **教练提示**：这部分是“死记硬背”的语法事实，直接看懂、记住即可，不需要猜。

**一句话定义**：在Java中，执行代码的最小单位是**线程（Thread）**。要开启一个新的线程去执行任务，最基础的两种方式就是：**继承 `Thread` 类** 或 **实现 `Runnable` 接口**。

**方式一：继承 `Thread` 类**
```java
// 1. 定义一个类继承 Thread，重写 run() 方法
class MyThread extends Thread {
    @Override
    public void run() {
        // 这里写新线程要执行的代码
        System.out.println("新线程在运行: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        // 2. 创建实例
        MyThread t = new MyThread();
        // 3. 调用 start() 启动线程（绝对不能调用 run()！）
        t.start(); 
        System.out.println("主线程在运行: " + Thread.currentThread().getName());
    }
}
```

**方式二：实现 `Runnable` 接口（🌟 工作中最常用）**
```java
// 1. 定义一个类实现 Runnable 接口，实现 run() 方法
class MyTask implements Runnable {
    @Override
    public void run() {
        System.out.println("新任务在运行: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        // 2. 创建任务实例
        MyTask task = new MyTask();
        // 3. 将任务传给 Thread 对象，并调用 start()
        Thread t = new Thread(task);
        t.start();
        
        // 快捷写法（Lambda表达式），工作中极度常用：
        // new Thread(() -> System.out.println("Lambda线程运行")).start();
    }
}
```

⚠️ **最核心的易错点提醒**：
**启动线程必须调用 `start()` 方法，绝对不能直接调用 `run()` 方法！**
- 调用 `start()`：JVM 会向操作系统申请创建一个真正的底层线程，然后由操作系统调度去执行 `run()` 里的代码（这是真正的多线程并发）。
- 调用 `run()`：这只是一次普通的方法调用，代码依然在当前线程（主线程）里同步执行，根本没有开启新线程！
